## About

Flappy Bird 64-bit is a free, non-commercial fan project that recreates the
2013 mobile game Flappy Bird for current Android phones and tablets.

The original game was removed from app stores in 2014. Its Android release
was built for older 32-bit devices, and many current phones can no longer
install or run it. I started this project so the game stays playable on
modern hardware.

The game is written from scratch in Java and is based on version 1.3 of the
original Android release. By default it plays like the original. Optional
features and settings are available for players who want to change how the
game looks and feels.

---

## Features

### Gameplay
- The classic tap-to-flap gameplay
- An optional "Classic feel" preset that closely recreates the physics of
  the original 1.3 release, including gravity, flap strength, pipe layout,
  hitbox, scoring and bird tilt
- Medals, high score, day and night backgrounds, and three bird colors

### Modern Android support
- Built for 64-bit devices and Android 17
- Works in portrait and landscape
- Supports phones, tablets, foldables, split-screen and resizable windows
- Runs smoothly on 60, 90, 120 and 144 Hz displays
- Adjusts for camera cutouts and system bars

### Customization
A full settings menu with a live preview that shows each change as you
make it.

- Bird: color, tint, size, hitbox, wing speed, trail, rainbow and ghost
  effects, and starting position
- World: background, sky and ground speed, day and night cycle, and rain,
  storm or snow
- Pipes: color, width, gap, spacing, height variation, moving pipes and
  golden pipes
- Physics: gravity, flap strength, game speed, a difficulty ramp, points
  per pipe and medal scores
- Effects: screen shake, motion blur, screen dimming and the crash flash
- Modes: god mode, extra lives, autopilot, jetpack, drunk mode, upside
  down and reverse pipes
- System: sound and weather volume, vibration, pause button, auto-pause,
  FPS counter and hitbox outlines
- Advanced: fixed 60 Hz physics, whole-pixel movement, fall speed limit,
  tilt behavior, ceiling and scoring point

### Settings tools
- Three save slots for your favorite setups
- Export and import all settings as a .json file
- Share your setup as text, or paste one someone sent you
- Undo for randomize, reset, load, import and preset changes
- Reset settings or your high score separately

### Privacy
- No ads, in-app purchases or accounts
- No analytics or tracking
- Your settings and high score are stored only on your device

## Installation

1. Download the latest APK from the **Releases** page of this repository.
   Older versions are also available in the
   [Mediafire folder](https://www.mediafire.com/folder/at8q4prpl59m6/Flappy+Bird+64-bit+Recreation).
2. Open the downloaded file.
3. If Android asks, allow your browser or file manager to install apps
   from unknown sources.
4. Follow the on-screen prompts to finish installing.

### Updating
Install the new APK over the existing one. If Android shows
"App not installed," uninstall the previous version first and then install
the new one.

Uninstalling deletes your settings and high score. To keep your settings,
use **Settings > Presets > Export to file** before uninstalling, then
import the file afterward.
